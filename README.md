# AfriConnect Summit 2026

## À propos du projet

AfriConnect Summit 2026 est un site web moderne conçu pour promouvoir un sommet technologique panafricain. Les visiteurs peuvent découvrir le programme de l'événement, les intervenants, les informations d'inscription et explorer les différentes activités proposées.

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript 
- Google Fonts
- Font Awesome

---

## Fonctionnalités

- Dark Mode / Light Mode
- Navbar responsive avec menu mobile
- Animations au défilement (IntersectionObserver)
- Compte à rebours avant l'événement
- Animation des compteurs
- Onglets interactifs du programme
- Filtrage dynamique des intervenants
- Validation du formulaire d'inscription
- Bouton de retour en haut
- Année dynamique dans le footer
